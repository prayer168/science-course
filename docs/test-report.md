## 2026-09-30｜新增跨年級課程銜接

### 已驗證

- 使用 Node.js 24.15.0 編譯檢查頁面 inline JavaScript：通過。
- `git diff --check`：通過，沒有空白錯誤或衝突標記。
- 解析 `course-data` JSON：180 個單元可讀取；每個單元由同一渲染迴圈產生可鍵盤操作的按鈕，點擊後會開啟說明對話框。無法建立主題連結的單元也會顯示「沒有找到可直接驗證的跨年級同主題單元」，不偽造連結。
- 解析銜接索引：12 條主題至少出現在兩個不同年級；只在單一年級出現的主題不會進到底部索引。
- 檢查「溶解、水溶液與混合物分離」：目前清單中有三、四、五、六、八年級的相關章名／活動；七、九年級沒有直接對應的三版本單元，畫面會明示空檔。五至八年級主題由各版水溶液、酸鹼、分離等單元文字判定，並以課綱 Jb、Jd 核對概念方向。
- 各主題只比對單元名稱、標籤和原有活動文字；課綱依據及推論限制已寫入 `docs/references.md`。
- 鍵盤操作使用原生 `<button>`、`<dialog>`（含 Esc 關閉與關閉後焦點回復）；對話框內容可捲動；手機窄畫面改單欄；支援 `prefers-reduced-motion`。
